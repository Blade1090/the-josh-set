# Matty NES isolation rule

Matty's NES Shelf Check must be a separate application, repository, deployment, storage namespace, cache/PWA identity, and data set from Josh's PS4 Shelf Check.

No NES application code or Matty ownership data is to be merged into PS4 `main`.

The existing `nes-matty-bootstrap` work and NES research package are reference inputs only. The final NES app is to be created outside this repository.
