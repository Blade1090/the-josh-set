## Compilation/component rule

Component identities should intentionally display the compilation's real physical box when that compilation is the only PS4 physical fulfillment path. This is not considered placeholder art.

Examples already following the intended rule include the classic Tomb Raider component identities fulfilled by Tomb Raider I-III Remastered / IV-VI Remastered.
